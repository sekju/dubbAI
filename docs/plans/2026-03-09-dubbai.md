# DubbAI Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Zbudować lokalnie uruchamialny, produkcyjnie zorientowany monorepo DubbAI z FastAPI, Celery, Redis, Postgres, Next.js i integracjami R2/Gemini.

**Architecture:** Monorepo z modułowym backendem FastAPI i workerem Celery oraz frontendem Next.js. Wszystkie ciężkie zadania multimedialne działają asynchronicznie, a stan biznesowy jest utrwalany w Postgres, pliki w R2.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy, Celery, Redis, Postgres, ffmpeg-python, yt-dlp, boto3, httpx, Next.js, React, Tailwind CSS, Zustand, Vitest, Pytest
